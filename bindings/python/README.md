# Biological rhythms dataset: Python bindings

Python bindings for [biological-rhythms-dataset](https://github.com/chethandvg/biological-rhythms-dataset), built from the Rust core with PyO3 and maturin. Function names and results are identical to the Rust crate; the shared golden vectors check it in CI.

```bash
pip install "git+https://github.com/chethandvg/biological-rhythms-dataset@v0.1.0#subdirectory=bindings/python"
```
